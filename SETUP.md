# Bhumi3D — Local Setup Guide

Bhumi3D is a Smart India Hackathon prototype for:

**3D ULPIN Generation and Vertical Property Mapping**

The project currently contains:

- React frontend
- CesiumJS 3D viewer
- FastAPI backend
- PostgreSQL database
- PostGIS spatial processing
- 4 demo land plots
- 4 different buildings
- 4 floors per building
- 4 apartments per floor
- 64 vertical apartment parcels
- Linked spatial IDs
- Property search
- Topology validation
- GeoJSON import
- Automatic vertical parcel generation
